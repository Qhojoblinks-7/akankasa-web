# How This Website Works

## What This Site Does
- Helps people learn the Akan language
- Shares information about Akan culture, history, and traditions
- Lets users search a bilingual dictionary
- Connects the community through events and discussions

## How Content Is Organized

The website is built around four main areas:

1. **Language Learning** — Lessons, vocabulary, and greetings for all levels
2. **Culture** — Articles and stories about traditions, history, music, and more
3. **Dictionary** — A searchable list of Akan words with English translations
4. **Community** — Events, forums, and shared contributions

## Admin Area

The admin dashboard lets authorized users manage all content through simple forms:

- **Dictionary** — Add or edit words with their translations and audio
- **Lessons** — Create structured lessons for learners
- **Vocabulary** — Build word lists and flashcard modules
- **Greetings** — Manage common phrases and their pronunciations
- **Articles** — Write and publish culture stories
- **Documents** — Upload research papers and learning materials
- **Events** — Schedule community gatherings and workshops
- **Legal Pages** — Update privacy policy and terms of service
- **Homepage** — Change the main page sections and featured content

Each section has a list view and an editor. You can create new entries, edit existing ones, or remove content. Changes are saved immediately.

## Accessibility

The site is designed to work for everyone, including users with disabilities. It follows accessibility standards so people can use keyboards, screen readers, and adjustable text sizes.

## Mobile Ready

The site adapts to phones, tablets, and computers automatically.
